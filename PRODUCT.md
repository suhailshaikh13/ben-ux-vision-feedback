# Product

## Platform

web (static)

## Stack

Plain HTML/CSS/JS on GitHub Pages. Persistence via Google Sheets through a public Apps Script web app.

## Users

- **Respondents:** Pune teammates after Ben’s UX Design Vision session — leave a rating, optional note / Ask Ben question, no sign-in.
- **Host (Suhail):** Shares the Pages link; reviews responses on the page and/or in the Sheet.

## Product Purpose

Zero-friction post-event feedback. Success = open one link, submit in under two minutes, see the room’s responses without running a local server.

## Constraints

- GitHub Pages is static-only; Sheet + Apps Script is the write path.
- Web app access is “Anyone” — open write for the event window.
